# Cody's Shack Legacy

Welcome to the **Cody's Shack Legacy**! In this repository, you'll find everything from the very first version of Cody's Shack, when it was just a small game site - but everything here is now updated and maintained.

For the newer version of Cody's Shack, please [click here](https://github.com/codys-shack)!

---

Welcome to Cody's Shack, a self-deployable, good-looking game site based off of 3kh0 Lite.

## Why use it?

- No trashy UI
- Over 140 games, and you can add more!
- Loads quickly
- Easy to deploy

## Deploy it yourself

1. Choose your web hosting platform
   - We recommend using [Cloudflare Pages](https://pages.dev), [Vercel](https://vercel.com), [Netlify](https://netlify.com), [Render](https://render.com), or any other equivalent service
2. Fork this repository: [Click here](https://github.com/codys-shack/legacy/fork)!
   - Please leave this repository a star as well! It helps out a ton :D
3. On whatever web hosting platform you chose, host this repository as a static site.
   - If you're confused about this, just take a look at the documentation for your platform.
4. Enjoy! If you'd like to add more games to your fork, just take a look below

## Adding games

It's pretty easy! All you need to do is grab your game folder, drop it in `/games`, and then add it to the configuration file.

- `/config/games.json`: It contains the games' names, icons, and links. It's pretty self-explanatory.
